버스앱 v2.9 수정사항

1. 화면 단순화
- 큰 홍보 영역, 빠른 목적지 카드, 도움말, 하단 내비게이션 제거
- 출발지 → 도착지 → 버스 찾기의 2단계 흐름으로 정리
- 실시간 위치와 알림은 버스를 선택한 뒤에만 표시

2. 출발지 기준 도착 정류장 제한
- 출발 정류장을 선택하면 해당 정류장에 정차하는 전체 경기버스 노선을 확인
- 각 노선에서 출발 정류장 순번 뒤에 있는 정류장만 모아 도착지 목록으로 표시
- 반대 방향 또는 이미 지나간 정류장은 도착지 목록에서 제외
- 도착지 입력창은 공공 API 전체검색이 아니라 가는 방향 목록 안에서만 필터링

3. 즐겨찾기 5곳
- 도착지 즐겨찾기를 최대 5곳으로 제한
- 화면 상단에서 바로 선택하거나 개별 삭제 가능
- 현재 출발지에서 갈 수 없는 즐겨찾기는 선택하지 않고 안내 표시

4. 기타
- 시간 입력값의 세로 중앙 정렬 보완
- 서비스워커 캐시 v29 및 앱 버전 2.9.0 적용
