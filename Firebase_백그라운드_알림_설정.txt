Firebase 백그라운드 버스 알림 필수 설정

1. Firebase 콘솔 → Authentication → 로그인 방법에서 익명(Anonymous)을 사용 설정합니다.
2. Firestore Database를 생성합니다.
3. 프로젝트의 firestore.rules와 functions 폴더를 배포합니다.
4. 앱을 새로 열고 노선을 다시 선택한 뒤 “알림 허용하고 저장”을 다시 누릅니다.

중요
- 앱 화면을 열어둔 동안의 30초 간격 로컬 알림은 Firebase Functions 없이도 동작합니다.
- 화면이 꺼진 상태의 1분 간격 자동 감시는 functions/watchBusAlerts 배포가 필요합니다.
- Firebase 콘솔에 Spark 요금제로 표시된다면 Cloud Functions를 새로 배포할 수 없습니다. 백그라운드 자동 감시를 사용하려면 Blaze 요금제로 전환하고 예산 알림을 설정해야 합니다.
- 예약 함수는 Cloud Scheduler를 사용합니다.

배포 명령
npm install -g firebase-tools
firebase login
cp .firebaserc.example .firebaserc
# .firebaserc에 bus 프로젝트 ID 입력
cd functions
npm install
cd ..
firebase functions:secrets:set GBIS_SERVICE_KEY
firebase deploy --only functions,firestore:rules
