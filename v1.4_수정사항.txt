버스 위치·내 주변 정류장 오류 수정 v1.4

1. 내 주변 정류장
- 빠른 위치 확인 후 정확도 우선 재확인
- iPad·iPhone 위치 시간초과 시 자동 재시도
- API 검색 반경 경계에서 결과가 없을 때 주변 지점 보조 조회
- 정류장 좌표로 실제 거리 재계산 및 가까운 순 정렬
- 위치 권한·위치 서비스·API 오류를 구분하여 안내

2. 오는 버스 표시
- 기본 화면에서 탑승 정류장을 이미 지난 차량은 숨김
- 도착정보의 vehId1·vehId2를 버스위치정보와 결합
- 위치 API에서 차량이 잠깐 누락되어도 locationNo1·2로 예상 위치 표시
- 첫 번째·두 번째 도착 차량에 1·2 배지 표시
- ‘오는 버스 / 전체 차량’ 전환 버튼 추가
- 전체 차량 화면에서 지난 차량은 회색으로 표시

3. 도착 카드
- 빈 응답이 0분으로 보이던 오류 수정
- 실제 0분은 ‘곧 도착’, 빈 값은 ‘정보 없음’으로 구분
