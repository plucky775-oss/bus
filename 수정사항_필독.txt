호계 버스 알림 앱 수정본 1.1.0

[수정한 문제]
1. 공공데이터포털 인증키가 Encoding/Decoding 어느 형태든 한 번만 인코딩되도록 수정
2. 공공 API가 XML 오류를 반환해도 원인을 읽도록 수정
3. HTTP 403일 때 필요한 API 이름을 화면에 표시하도록 수정
4. GBIS 결과코드 4(검색 결과 없음)를 오류가 아닌 빈 목록으로 처리
5. API 시간초과, 인증키 오류, 호출량 초과를 구분해 표시
6. Firebase 백그라운드 도착정보 호출에도 같은 인증키/오류 처리를 적용

[중요: 현재 403의 실제 원인]
공공데이터포털에서 “경기도_버스위치정보 조회”만 승인된 상태라면
앱 첫 화면의 정류장 검색은 계속 403이 발생합니다.
아래 네 API를 각각 활용신청해야 전체 기능이 동작합니다.

- 경기도_정류소 조회
- 경기도_버스노선 조회
- 경기도_버스위치정보 조회
- 경기도_버스도착정보 조회

네 API는 같은 공공데이터포털 일반 인증키를 GBIS_SERVICE_KEY로 사용하면 됩니다.
승인 후 GitHub에 수정 파일을 덮어쓰고 Vercel에서 Redeploy 하세요.
