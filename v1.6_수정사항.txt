버스앱 v1.6 수정사항

1. 내 위치 주변 정류장
- iPad/iPhone GPS를 여러 번 확인해 가장 정확한 좌표 사용
- 현재 좌표와 동서남북/대각선 보조 좌표를 함께 조회
- 실제 거리 재계산 후 1.1km 이내 정류장을 가까운 순서로 표시
- 위치 정확도와 검색 상태 문구 추가

2. 오는 버스
- 기본 표시를 전체 차량이 아닌 '오는 버스'로 변경
- 도착정보 API의 1·2번째 차량을 위치정보와 병합
- 위치정보에 차량이 누락돼도 도착 정류장명/남은 정류장 수로 추정 마커 표시
- 운행 차량 목록과 갱신 시각 추가
- 일시적인 빈 응답 시 최근 정상 위치를 최대 90초 유지

3. 노선 지도
- 노선형상 좌표 x/y 자동 교정
- 실제 노선형상을 이중 선으로 표시하고 경유정류소 선을 보조로 표시
- 비정상적으로 멀리 튀는 좌표 구간 자동 분리
- 버스 마커에 노선번호와 차량번호 끝자리 표시

4. 새로고침
- 기존 요청이 멈춰 있어도 수동 새로고침 시 취소 후 즉시 재요청
- 요청 제한시간과 갱신 시각 표시
- 앱 캐시 버전 1.6.0으로 갱신
