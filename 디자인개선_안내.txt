우리 버스 알림 v1.2 프리미엄 UI 전면 개편

[주요 변경]
- 기능검증용 화면을 미래지향적 교통앱 스타일로 전면 재설계
- 생성한 버스 위치 아이콘을 앱 아이콘·홈 화면 아이콘·상단 브랜드 심볼에 적용
- 호계 e편한세상 → 평촌 경로가 한눈에 보이는 출발/도착 패널 적용
- 평촌고·평촌학원가 빠른 선택 카드 개선
- 검색·직행노선·실시간 도착·알림설정 카드의 정보 계층 재구성
- 실시간 API 연결 상태, 자동 갱신 상태, 푸시 알림 상태 시각화
- iPhone/iPad/Android/PC 반응형 레이아웃 개선
- 기존 GBIS API 및 Firebase 기능은 그대로 유지
