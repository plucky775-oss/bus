버스앱 v2.0 수정사항

1. 내 주변 정류소 조회
- 주변정류소 응답 태그 busStationList / busStationAroundList 모두 처리
- v2 주소 결과가 비면 구형 호환 주소 자동 재시도
- GPS 중심, 420m 격자, 840m 격자 순으로 최대 약 1.8km 범위 보조 조회
- API 일시 실패 시 각 지점을 재시도하고 중복 정류소를 실제 거리순으로 정리

2. 버스번호별 알림 저장
- 선택한 노선마다 시작/종료시간, 요일, 정거장 수, 알림 방식을 별도 저장
- 저장된 버스 알림 목록과 삭제 기능 추가
- Firebase 문서도 노선ID+탑승정류장 기준으로 각각 유지
- 기존 단일 로컬 알림을 새 다중 알림 형식으로 자동 이전

3. 시간 입력 겹침 수정
- 시간 입력 높이와 글자 크기를 줄이고 iPhone/iPad Safari 최소 폭 문제 수정
- 좁은 화면에서도 시작/종료 시간이 두 칸 안에서 겹치지 않도록 조정
