버스 실시간 표시·알림 안정화 v1.5

1. 공식 노선형상정보 API를 이용해 선택한 버스의 실제 운행 경로를 굵은 선으로 지도에 표시
2. 지도 기본값을 “전체 차량”으로 변경하여 운행 차량이 숨지 않도록 수정
3. 각 버스 마커에 선택한 버스 번호와 차량번호 끝 4자리 표시
4. 도착정보 API가 실패해도 노선·버스위치가 계속 표시되도록 호출 분리
5. 버스위치 API가 실패해도 노선 자체는 지도에 표시
6. 노선 경유정류소의 실제 stationSeq를 기준으로 출발·도착 순번을 재보정
7. stationId·stationSeq 필드 차이를 보정하여 버스 마커 누락 감소
8. 새로고침 버튼에 로딩 표시·완료 안내 추가
9. Firebase 익명 로그인이 꺼져 있어도 앱 전체 푸시 초기화가 중단되지 않도록 수정
10. auth/configuration-not-found 발생 시 정확한 설정 경로 표시
11. 캐시 버전을 1.5로 올려 배포 후 이전 app.js가 남는 문제 방지

중요: 화면이 꺼진 상태의 백그라운드 알림을 사용하려면 Firebase 콘솔에서
Authentication → 로그인 방법 → 익명(Anonymous)을 사용 설정해야 합니다.
또한 functions/watchBusAlerts와 Firestore 규칙이 Firebase에 배포되어 있어야 합니다.

12. 백그라운드 함수에서 flag 값이 비어 있어도 정거장 수가 조건에 맞으면 알림하도록 수정
